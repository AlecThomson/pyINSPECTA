# SDHDF definition templates

`sdhdf_template_v{2.9,3.0,4.0}.hdf` are the template files of the SDHDF
definition, from:

> Toomey, L. (2026): Spectral-Domain Hierarchical Data Format (SDHDF)
> Definition. v4. CSIRO. Data Collection. https://doi.org/10.25919/q1hf-8p06

They are licensed under the
[Creative Commons Attribution 4.0 International Licence](https://creativecommons.org/licenses/by/4.0/)
and are included unmodified, for testing.
